# HydroSense — Landing Page (TB2)

Plataforma web y ecosistema IoT orientado al monitoreo inteligente del consumo hídrico residencial y comunitario (ODS 6: Agua Limpia y Saneamiento), desarrollado para el curso **HCI for UX Design (1ASI0784 — NRC 15276)** de la **Universidad Peruana de Ciencias Aplicadas (UPC)**.

- **Repositorio GitHub:** https://github.com/aokai77/HydroSense-Landing
- **Despliegue en GitHub Pages:** https://aokai77.github.io/HydroSense-Landing/

---

## Estructura del Repositorio

- `assets/` — Fuentes, íconos SVG, imágenes y videos del proyecto
- `css/` — Hojas de estilo (`styles.css`, `responsive.css`)
- `docs/` — Documentación funcional (`README.md`)
- `js/` — Lógica interactiva y simuladores (`main.js`)
- `pages/` — Vistas internas de la aplicación (`monitoreo.html`)
- `index.html` — Página principal de la Landing Page
- `favicon.ico` — Ícono de pestaña del navegador
- `.gitignore` — Exclusiones de archivos locales y temporales
