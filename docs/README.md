# HydroSense - Landing Page

Proyecto web desarrollado para **HydroSense**, una solución inteligente orientada al monitoreo del consumo residencial de agua, detección temprana de fugas mediante IoT y gestión sostenible del recurso hídrico (alineado al ODS 6: Agua limpia y saneamiento).

## Enlaces del Proyecto
* **Repositorio:** https://github.com/TU_USUARIO/HydroSense-Landing
* **Sitio Web (GitHub Pages):** https://TU_USUARIO.github.io/HydroSense-Landing/

## Estructura del Repositorio
El proyecto sigue una arquitectura organizada de recursos estáticos:

```text
HydroSense-Landing/
├── assets/
│   ├── fonts/          # Tipografías personalizadas
│   ├── icons/          # Iconografía vectorial SVG (chart, drop, home_iot, leaf)
│   ├── images/         # Recursos gráficos e ilustraciones
│   └── videos/         # Recursos audiovisuales
├── css/
│   ├── styles.css      # Estilos principales, paleta de colores y layout
│   └── responsive.css  # Adaptabilidad móvil y media queries
├── docs/
│   └── README.md       # Documentación general del repositorio
├── js/
│   └── main.js         # Lógica interactiva, validaciones y dinamismo de la interfaz
├── pages/              # Vistas adicionales o secciones complementarias
├── .gitignore          # Archivos y carpetas excluidos del control de versiones
├── favicon.ico         # Ícono de pestaña del navegador
└── index.html          # Página principal (Landing Page)
